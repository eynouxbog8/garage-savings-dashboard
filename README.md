# Garage Savings Dashboard (synthetic data)

Power BI dashboard analysing savings from declined or reduced garage charges.

> **All data is synthetic.** Generated by `generate_synthetic_data.py` (fixed seed).
> No real employer, garage, vehicle or claim data is used.

## Data model (star schema)
`fact_claims` -> `dim_garage`, `dim_charge_type`, `dim_decline_reason` (+ a Date table built in Power BI)

| Column | Meaning |
|---|---|
| requested_amount | £ the garage asked for |
| approved_amount | £ actually paid |
| amount_saved | requested - approved |
| mapped_miles / requested_miles | mileage claims only; blank otherwise |

## Business questions
1. How much did we save, and where does it come from?
2. Which charge types and decline reasons drive savings?
3. Which garages repeatedly over-claim?
4. How does mileage inflation (requested vs mapped) vary?
